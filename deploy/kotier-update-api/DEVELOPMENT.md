# Kotier 更新服务缓存改造开发记录

## 目标

让更新服务继续从 GitHub Release 获取最新版本号和更新说明，同时把 APK 下载到服务器缓存，并通过 `kotier.wotty.app` 与 `kotier.openstars.org` 提供国内下载。

## 实施步骤

1. 更新 Node 服务：读取 GitHub 最新 Release，生成当前请求域名对应的自有下载地址。
2. 增加 APK 缓存目录、临时文件原子落盘、并发下载复用和 HTTP Range 支持。
3. 更新 Compose 持久化挂载，保证容器重启不会丢失已缓存的安装包。
4. 本地执行语法检查和接口/下载行为验证。
5. 通过 Ops Control 更新服务器项目并检查服务状态。
6. 验证新旧域名的版本信息、APK 下载和断点范围请求。
7. 更新版本记录并提交本地 Git；仅在用户明确要求时推送到 GitHub。

## 约束

- 不覆盖历史版本 APK。
- APK 只在完整下载后从 `.part` 文件原子改名为正式文件。
- GitHub Release 正文作为更新说明来源。
- 旧域名继续兼容旧版客户端。
